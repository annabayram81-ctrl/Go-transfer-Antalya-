# GoTransfer

Минималистичный статический сайт для заказа трансфера по Анталье и курортным локациям региона.

## Локальный запуск

```bash
node local-server.mjs
```

Сайт откроется на `http://127.0.0.1:4173`.

## Настройка

Основные данные лежат в `booking.js`:

- `whatsappPhone` - номер WhatsApp в международном формате без `+`.
- `telegramUsername` - username Telegram без `@`.
- `locations` - предустановленные локации.
- `prices` в каждой локации - тарифы для `1-3`, `4-6`, `7-9` пассажиров.
- `tariffTiers` - диапазоны пассажиров, базовая часть и расчетная стоимость километра.
- `routeMatrixIds` и `routeDistancesKm` - дорожная матрица расстояний между всеми локациями.
- `translations` - тексты интерфейса и WhatsApp-сообщения для русского, английского и турецкого.

Для маршрутов с `Antalya Airport` используются точные цены из таблицы. Для остальных пар локаций цена считается по дорожному расстоянию и тарифной модели, выведенной из аэропортовых цен.
Для `10-20` пассажиров используется тариф `7-9` с надбавкой 10% и округлением вверх до ближайших `€5`.

## Vercel

Проект можно деплоить как статический сайт. В Vercel выберите этот репозиторий/папку, оставьте build command пустым, а output directory - корень проекта.

Если используете Vercel CLI:

```bash
vercel
```
