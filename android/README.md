# GoTransfer Android

Native Android WebView wrapper for `https://antalya-transfer.vercel.app`.

## Requirements

- Android Studio with Android SDK Platform 35.
- JDK 17.
- Gradle wrapper generated by Android Studio, or a local Gradle installation.

This repository does not commit Android SDK paths, keystores, or signing passwords.

## Build

From the `android/` directory:

```bash
gradle :app:assembleDebug
```

After Android Studio generates a Gradle wrapper, prefer:

```bash
./gradlew :app:assembleDebug
```

## Release Signing

Create a keystore outside the repository and expose signing values through environment variables or private Gradle properties:

```bash
export GOTRANSFER_STORE_FILE=/absolute/path/gotransfer-upload.jks
export GOTRANSFER_STORE_PASSWORD=...
export GOTRANSFER_KEY_ALIAS=gotransfer
export GOTRANSFER_KEY_PASSWORD=...
```

Then build release artifacts:

```bash
./gradlew :app:bundleRelease
./gradlew :app:assembleRelease
```

Use the `.aab` for Google Play and RuStore. Use the signed `.apk` only when RuStore or direct installation specifically needs APK distribution.

## App Behavior

- Package name: `com.gotransfer.antalya`.
- App label: `GoTransfer`.
- WebView source: `https://antalya-transfer.vercel.app`.
- Only the GoTransfer production host opens inside WebView.
- WhatsApp, Telegram, phone, mail, and other external URLs open through Android intents.
- Cleartext HTTP traffic is disabled.
- No `addJavascriptInterface` bridge is exposed.
